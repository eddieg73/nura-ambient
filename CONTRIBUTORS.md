## Getting access

The repository is public, so reading requires nothing:

    https://github.com/eddieg73/nura-ambient

**Reading the code, the docs and the tests needs no account and no invitation.**

Push access is by GitHub username. GitHub's REST API cannot invite a
collaborator by email address - the collaborator endpoint requires a login - so
write access is granted once the username is known. Send it to eg@nuratech.ai
and it will be added.

Note: no GitHub account is publicly associated with oussama@nuratech.ai, so the
username has to be stated rather than inferred. It will not be guessed.
